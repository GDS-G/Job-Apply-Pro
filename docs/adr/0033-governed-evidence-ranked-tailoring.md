# ADR-0033: Governed evidence-ranked tailoring

- Status: Accepted
- Build: Evidence-Ranked Tailoring `v0.24.0-alpha.1`

## Context

Tailored documents already use only locked verified claims approved for applications, report missing requirements, bind generation to an exact preview fingerprint, encrypt generated bytes, and retain submitted-version evidence. Selection was limited to deterministic token overlap and rendering used one plain style. The authoritative roadmap calls for richer templates and semantic ranking only through the governed AI boundary with deterministic fallback and preserved evidence identity.

## Decision

Add PROFESSIONAL and COMPACT template choices for DOCX and PDF. Rendering remains deterministic and local; templates adjust margins, body size, leading, and spacing but never invent or transform evidence text.

Add DETERMINISTIC and GOVERNED_AI ranking modes. The deterministic baseline remains token overlap with stable canonical-key and ID tie-breaking. GOVERNED_AI sends only job title, employer, requirements, and locked application-approved claim statements through AIGatewayService.rerank using EMPLOYMENT_SENSITIVE classification. External providers require the request's explicit external consent; local providers do not. The gateway continues to own routing, privacy, redaction, schema validation, retries, budgets, cache, and sanitized audit records.

Missing configuration, unavailable routes, policy rejection, gateway validation failure, duplicate/out-of-range indexes, or empty positive rankings produce a visible DETERMINISTIC_FALLBACK. The actual method and notice are included in the exact preview fingerprint. Generation recomputes the preview and refuses stale approval.

Migration 20260812_0016 retains template, requested ranking mode, and actual ranking method in each generation audit. Selected claim IDs, matched requirement IDs, missing required requirements, and review fingerprint remain unchanged.

## Consequences

- Operators can choose compact or professional output without changing evidence.
- Governed reranking may improve claim order while never authorizing new claims or free-form model prose.
- A route failure cannot silently weaken evidence selection; the fallback is visible and fingerprinted.
- Existing API requests remain deterministic/professional by default, but desktop IPC requires explicit typed values from the updated renderer.
- Live external ranking remains gated on owner configuration, current terms/privacy review, and explicit per-preview consent.
