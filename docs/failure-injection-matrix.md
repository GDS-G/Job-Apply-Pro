# Production failure-injection matrix

This matrix is the authoritative Phase 12 resilience checklist. "Automated" means a repeatable repository or packaged-runtime gate. "Release lab" means the exact signed candidate must be exercised on an isolated supported Windows workstation. "Authorized integration" additionally requires an approved provider or portal account.

| Failure                                          | Expected behavior                                                                                    | Evidence/gate                                                               | Scope                      | Status                                         |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | -------------------------- | ---------------------------------------------- |
| Invalid loopback API token                       | Reject privileged request with 401; health remains available                                         | `test_configured_local_api_token_protects_privileged_routes`                | Automated                  | Passing                                        |
| External browser origin while production locked  | Reject before navigation                                                                             | `test_browser_runtime_rejects_external_origins_when_production_is_locked`   | Automated                  | Passing                                        |
| Browser worker restart                           | Restore persistent profile/checkpoint and continue only from verified state                          | Browser runtime and Workbench restart tests                                 | Automated                  | Passing                                        |
| Frozen browser worker missing or launch fails    | Controlled unavailable error; no arbitrary Python fallback                                          | `test_browser_worker_packaging.py`; both delivered-copy loopback smoke paths | Automated/packaged         | Passing at v0.53                               |
| Packaged browser worker parent closes IPC        | Exact captured worker exits successfully after backend shutdown                                     | `test_packaged_backend.ps1` direct/API lifecycle smoke                       | Packaged loopback          | Passing at v0.53; not process-tree containment  |
| CAPTCHA                                          | Pause, preserve prior state, require direct intervention, re-observe before resume                   | `test_captcha_requires_intervention_and_resumes_saved_state`                | Automated                  | Passing                                        |
| Changed selector/page/modal                      | Invalidate fingerprint or postcondition; retry/takeover rather than infer success                    | Portal replay fingerprints, browser postconditions, challenge refresh tests | Automated/replay           | Passing                                        |
| Invalid model structure                          | Retry boundedly, then reject; never execute unvalidated output                                       | `test_invalid_structured_output_is_retried_then_rejected`                   | Automated                  | Passing                                        |
| Restricted model data or missing consent         | Block external call and redact permitted data                                                        | AI privacy test                                                             | Automated                  | Passing                                        |
| Provider unavailable/not configured              | Fail closed and retain failed mutation audit                                                         | Disabled communication/calendar tests                                       | Automated                  | Passing                                        |
| Duplicate provider write                         | Reuse idempotency result; do not send/create twice                                                   | Send/calendar idempotency tests                                             | Automated                  | Passing                                        |
| Incorrect attachment/profile version             | Reject before upload/write                                                                           | Attachment verification test                                                | Automated                  | Passing                                        |
| Lost or weak submission confirmation             | Record attempted/uncertain, never confirmed                                                          | Workflow verification and portal confirmation tests                         | Automated                  | Passing                                        |
| Tampered encrypted value                         | AES-GCM authentication failure                                                                       | Encryption tamper test                                                      | Automated                  | Passing                                        |
| Tampered backup/archive drift                    | Reject before staging                                                                                | Backup tamper and manifest drift tests                                      | Automated                  | Passing                                        |
| Changed restore fingerprint                      | Reject before filesystem replacement                                                                 | Offline restore rejection test                                              | Automated                  | Passing                                        |
| Missing staged restore file                      | Reject; current files remain recoverable                                                             | Offline restore missing-stage test                                          | Automated                  | Passing                                        |
| Backend open during restore                      | Prove owned child exit before exclusive restore; do not restart while a writer may survive          | Supervisor lifecycle tests; real owned-process stop and offline restore smoke | Automated/packaged       | Passing at v0.54 within documented scope        |
| Backend process termination                      | Surface degraded state; retain durable state/checkpoint                                              | Generation-owned supervisor, Workbench/browser restart tests                | Automated                  | Passing in source                               |
| Concurrent start / stop during migration         | One owned migration; cancelled generation cannot launch service or scheduling                       | `backend-supervisor.test.ts` fake child/timer and listener reentrancy tests | Automated                  | Passing in source                               |
| Restore observation timeout or nonzero exit      | Never kill writer on timeout; retain ownership and session-local recovery guard                     | Restore timeout/late-exit/update-bypass regression tests                     | Automated                  | Passing; durable crash marker still required    |
| Quit or update before owned child exit           | Await verified shutdown; block installer/relaunch after uncertain restore                           | Entry-point and update-manager lifecycle tests                              | Automated                  | Passing; signed/physical acceptance separate    |
| Migration rerun                                  | Remain idempotent at schema head                                                                     | Migration repeatability test; packaged migrate before and after restore     | Automated/packaged         | Passing                                        |
| Database replacement                             | Retain `.pre-restore`, restore files, rehydrate manifest/audit, migrate, restart, expose diagnostics | Source offline CLI test and `test_packaged_backend.ps1`                     | Automated/packaged         | Passing                                        |
| Missing OS encryption service                    | Abort first start; never write plaintext master key                                                  | `loadOrCreateMasterKey` fail-closed branch                                  | Code invariant/release lab | Manual candidate check required                |
| Network offline during portal/provider operation | Preserve checkpoint/audit and show retry/takeover                                                    | Disabled fixtures and bounded client errors                                 | Release lab                | Candidate check required                       |
| Expired provider login                           | Mark integration degraded/not configured; never expose token                                         | Credential-reference boundary                                               | Authorized integration     | External account required                      |
| Browser runtime unavailable                      | Surface controlled failure and preserve workflow                                                     | Browser error boundary                                                      | Release lab                | Candidate check required                       |
| Database held by another process                 | Migration/start must degrade without automation                                                      | Supervisor migration exit gate                                              | Release lab                | Candidate check required                       |
| Storage full or write denied                     | Atomic write must fail without replacing verified target                                             | Atomic temporary-write design                                               | Release lab                | Candidate check required                       |
| Sleep/resume and workstation restart             | Backend reconnects; durable state and schedules remain consistent                                    | Desktop lifecycle design                                                    | Release lab                | Candidate check required                       |
| Unsigned/wrong-publisher update                  | Reject and retain installed version                                                                  | `forceCodeSigning`, Authenticode verifier, updater signature verification   | Signed release lab         | Signing certificate required                   |
| New version rollback                             | Preserve user data; install prior signed binary; use compatible verified backup for schema rollback  | `docs/release-runbook.md`                                                   | Signed release lab         | Signing certificate and prior release required |

No manual or authorized-integration row may be reported as production-tested until its exact candidate evidence is attached to the release record.
