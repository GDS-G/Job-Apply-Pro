# Production failure-injection matrix

This matrix is the authoritative Phase 12 resilience checklist. "Automated" means a repeatable repository or packaged-runtime gate. "Release lab" means the exact signed candidate must be exercised on an isolated supported Windows workstation. "Authorized integration" additionally requires an approved provider or portal account.

| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | -------------------------- | ---------------------------------------------- |

| External browser origin while production locked  | Reject before navigation                                                                             | `test_browser_runtime_rejects_external_origins_when_production_is_locked`   | Automated                  | Passing                                        |
| Browser worker restart                           | Restore persistent profile/checkpoint and continue only from verified state                          | Browser runtime and Workbench restart tests                                 | Automated                  | Passing                                        |

| Packaged browser worker parent closes IPC        | Exact captured worker exits successfully after backend shutdown                                     | `test_packaged_backend.ps1` direct/API lifecycle smoke                       | Packaged loopback          | Passing at v0.53; not process-tree containment  |
| CAPTCHA                                          | Pause, preserve prior state, require direct intervention, re-observe before resume                   | `test_captcha_requires_intervention_and_resumes_saved_state`                | Automated                  | Passing                                        |
