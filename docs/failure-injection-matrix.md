# Production failure-injection matrix

This matrix is the authoritative Phase 12 resilience checklist. "Automated" means a repeatable repository or packaged-runtime gate. "Release lab" means the exact signed candidate must be exercised on an isolated supported Windows workstation. "Authorized integration" additionally requires an approved provider or portal account.

Reviewed Browser Exact URL Reconciliation `v0.79.0-alpha.1` is the active alpha candidate. Only one standard direct `NAVIGATE` carrying encrypted pre-dispatch intent for a different explicit allowlisted HTTP(S) target and exact `URL_EQUALS` verification can gain read-only recovery review. Two observations must prove the exact target URL/origin, changed fingerprint, bounded page type, and worker-maintained prior action; no navigation is replayed and original uncertainty remains immutable. Arbitrary link clicks, partial URLs, redirects and manual browsing receive no authority. Exact source checkpoint `5b7c59ea9a2c1bacc037ef953b2635ad44a53e17` passes 1,961 backend and 526 desktop tests at 86.52% backend coverage. Candidate checkpoint `0ec4bd1ef2189fca1f7aee2c2e1d63f74b1cd8d5` passes both package smokes and both delivered protocols; earlier evidence does not transfer. This work does not establish protected, signed, physical, or authorized live-provider acceptance.
