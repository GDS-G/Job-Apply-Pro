# Production failure-injection matrix

This matrix is the authoritative Phase 12 resilience checklist. "Automated" means a repeatable repository or packaged-runtime gate. "Release lab" means the exact signed candidate must be exercised on an isolated supported Windows workstation. "Authorized integration" additionally requires an approved provider or portal account.

Durable Restore Rollback `v0.61.0-alpha.1` is an alpha package-qualified candidate. Its 1,492-test full backend gate passes at 86.66% coverage; exact backend-dist/delivered-package smokes, delivered supervisor, and source-controller-to-delivered-backend recovery protocol also pass. Protected CI/security and physical installed Windows recovery evidence still must be attached.
